# 🔍 Caça aos Casais

Um joguinho para 4 casais: **Yuri & Duda, Álvaro & Andressa, David & Bianca, Sammya & Luís Gustavo**.

## Como funciona

A tela mostra uma cena de parque: um advogado de costas conversando com uma mulher
que segura um livro. As fotos das 8 pessoas estão escondidas em pontos da imagem —
clicando no lugar certo, a foto aparece:

- 📷 **Câmera do poste** → Yuri
- 🌸 **Uma flor do canteiro** (só uma!) → Duda
- 😁 **Dente da mulher** → Álvaro
- ✈️ **Avião passando no céu** → Andressa
- 🚜 **Terra no chão** → David (uma retroescavadeira vem desenterrar a foto!)
- 📘 **Livro da mulher** → Bianca
- 🐦 **Passarinho no galho da árvore** → Sammya
- 👔 **Cabeça do advogado** → Luís Gustavo

O progresso fica salvo no navegador. Tem botão de recomeçar, plaquinha de
"frio/quente" nos cliques errados e confete quando encontrar todo mundo. 🎉

## Como rodar

É um site estático — basta abrir o `index.html` no navegador, ou publicar no
GitHub Pages (Settings → Pages → branch principal).

## Adicionando as fotos

Veja as instruções em [`fotos/LEIA-ME.md`](fotos/LEIA-ME.md). Resumo: solte os
arquivos na pasta `fotos/` com os nomes `yuri.jpg`, `duda.jpg`, `alvaro.jpg`,
`andressa.jpg`, `david.jpg`, `bianca.jpg`, `sammya.jpg` e `luisgustavo.jpg`.
