# 🔎 Caça aos Amigos no Parque

Um joguinho para 4 casais: **Yuri & Duda · Álvaro & Andressa · David & Bianca · Luís Gustavo & Sammya**.

A cena mostra um advogado (de costas) conversando com uma mulher que segura um livro, num parque.
Oito fotos estão escondidas na cena — clique no lugar certo para revelá-las:

| Onde clicar | Quem aparece |
|---|---|
| 📹 Câmera no poste | Yuri |
| 🌸 Uma flor específica | Duda |
| 😁 Dente da mulher | Álvaro |
| ✈️ Avião ao fundo | Andressa |
| 🚜 Terra no chão (a retroescavadeira desenterra!) | David |
| 📖 Livro da mulher | Bianca |
| 🦋 Borboleta | Sammya |
| ⚖️ Cabeça do advogado | Luís Gustavo |

## Como adicionar as fotos

Coloque os arquivos na pasta `fotos/` com estes nomes:
`yuri.jpg`, `duda.jpg`, `alvaro.jpg`, `andressa.jpg`, `david.jpg`, `bianca.jpg`, `sammya.jpg`, `luis-gustavo.jpg`
(também aceita `.jpeg`, `.png` e `.webp`).

Enquanto a foto não existir, o jogo mostra um aviso no lugar dela — o resto funciona normalmente.

## Como rodar

É um site 100% estático (um único `index.html`). Opções:

- Abrir o `index.html` direto no navegador; ou
- Publicar no **GitHub Pages**: Settings → Pages → Deploy from branch → selecionar a branch e a pasta `/ (root)`.

O progresso (quem já foi encontrado) fica salvo no navegador; o botão **↺ Recomeçar o jogo** zera tudo.
